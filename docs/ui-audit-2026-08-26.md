## Findings and actions

- Customer-visible copy no longer names CLI/environment configuration,
  authentication mechanics, research-role internals, worker/planner pools,
  internal agent identifiers, or endpoint URLs.
- Empty, warning, session, document-viewer, capacity, and quality-review states
  state the next action in English and Korean.
- The mobile header no longer overlaps environment and region values, the model
  group member selector has a usable touch width, and the page has no horizontal
  document overflow at 390 px. Wide evidence tables remain horizontally
  scrollable inside their panels.
- Rendered visible text was checked for the audited internal terms and returned
  zero matches. The relevant admin and integration contract slice passed all 10
  tests.

This is a local rendering audit, not authenticated production-runtime evidence.
Repeat the same viewport and interaction audit against the deployed console
