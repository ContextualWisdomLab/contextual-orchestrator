Added a pure multi-model combination domain (`contextual_orchestrator/domain/`) and a parallel fan-out service (`contextual_orchestrator/application/fan_out.py`). Several workers can now answer the same task and be combined by plurality vote (self-consistency aggregation, arXiv:2203.11171), scorer-selected best-of-n, or Mixture-of-Agents aggregation (arXiv:2406.04692). Plurality uses the unique mode with no repository-defined support threshold, vote and score ties abstain, and fan-out defaults to no elapsed-time cutoff. Before this, `conduct` ran exactly one worker per plan. Serving and benchmark wiring follow in later ADR 0124 steps; see `docs/doctoring/multi_model_combination.md`.
