Added a `--verbose`/`--debug` CLI flag (also settable via `CONTEXTUAL_ORCHESTRATOR_VERBOSE=true` for an already-deployed server, without a CLI edit) that enables stdlib DEBUG-level logging of the route-vs-conduct decision, each route/conduct step's agent and latency, `ModelClient` provider request/retry/backoff attempts, `TaskOrchestrator._invoke`'s failover classification, per-agent circuit-breaker open/half-open/closed transitions, and the HTTP request/response lifecycle in `server.py`. Off by default with no behavior change; every new log record is bounded and secret-free by construction — never an API key, an `Authorization` header, a raw exception message, or prompt/response content (ADR 0125).
