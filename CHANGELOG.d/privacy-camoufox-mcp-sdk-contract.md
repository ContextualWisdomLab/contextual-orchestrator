Fixed the Camoufox MCP policy renderer's undeclared SDK contract: `privacy_policy_analysis` imports the MCP Python SDK 2.x client API (`mcp.Client`, `streamable_http_client(url, http_client=...)`), so a deployment carrying a 1.x `mcp` package failed with an opaque `cannot import name 'Client'` that `crawl_policy_document` silently swallowed into the static-text fallback, and the pinned-client test crashed with `AttributeError` instead of skipping. The renderer now raises an explicit `ImportError` naming the required `>= 2.0` SDK and the installed version, the pinned-client test skips on a pre-2.0 SDK with that reason, and a new test proves the version diagnostic against a 1.x stub. Verified with the installed 1.23.3 SDK (10 passed, 1 skipped) and an isolated `mcp==2.2.0` environment (11 passed).
