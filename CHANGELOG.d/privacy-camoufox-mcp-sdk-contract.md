Fixed the Camoufox MCP policy renderer's undeclared SDK contract: `privacy_policy_analysis` imports the MCP Python SDK 2.x client API (`mcp.Client`, `streamable_http_client(url, http_client=...)`), so a deployment carrying a 1.x `mcp` package failed with an opaque `cannot import name 'Client'` that `crawl_policy_document` silently swallowed into the static-text fallback, and the pinned-client test crashed with `AttributeError` instead of skipping. The renderer now raises an explicit `ImportError` naming the required `>= 2.0` SDK and the installed version, the pinned-client test now drives the 2.x surface through `sys.modules` stubs so it runs (and covers the import path) without the package installed, and new tests prove the version diagnostic against a 1.x stub and both states of the installed-version helper. Verified with the installed 1.23.3 SDK (12 passed) and the API introspected from an isolated `mcp==2.2.0` environment.
