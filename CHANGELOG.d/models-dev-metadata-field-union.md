Fixed `_merge_models_dev_metadata` silently discarding a provider's own catalog-reported `architecture`/`context_window`/`max_output_tokens` when Models.dev matched the model by id but had no `modalities`/`limit` data for it. The join now applies Models.dev's value only when Models.dev actually reports one for that field, falling back to the provider's own already-discovered value otherwise; free-model classification remains Models.dev-authoritative per ADR 0041's cost-safety argument. Added `test_models_dev_merge_unions_fields_instead_of_clobbering_provider_evidence` in `tests/test_model_discovery.py`.
