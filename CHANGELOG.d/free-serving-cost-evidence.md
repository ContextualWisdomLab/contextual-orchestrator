Introduced one shared free-serving predicate (`contextual_orchestrator.free_serving_evidence`) for discovery-time and serving-time selection. `ModelClient` classifies completed chat, passthrough, and stream responses from provider-reported `usage.cost`: a real JSON-number zero with explicit `is_byok: false` is observational `FREE` evidence, a positive cost is `PAID`, and a missing, malformed, non-finite, negative, or BYOK cost is `UNKNOWN`. Transport errors, non-2xx replies, truncated/non-JSON bodies, and incomplete streams record `UNKNOWN` for evidence-required providers; documented quota 429 responses and HTTP 402 record `EXHAUSTED`. No per-call cost response header is documented, so `REPORTED_COST_HEADER` remains unset and any future configured header is parsed fail-closed.

Experiential Labs promotion entries from the public keyless `GET https://api.experientiallabs.ai/api/models` catalog nominate candidates only; neither a promotion nor a prior zero-cost response proves that the next request is free. Experiential Labs therefore remains outside `orchestrator/free` until an authoritative pre-send entitlement contract is available. `probe_free_candidates` preserves its public receipt shape but always returns zero probes and never invokes its network callback, so a possibly billed request is never used to establish free eligibility. `PAID` and `EXHAUSTED` demotions persist until an explicit process-level ledger reset; no allowance-calendar assumption, clock-skew margin, probe budget, provider/model fallback, or paid bypass changes admission. Other providers retain catalog-price admission unless explicitly demoted. Evidence and demotion are scoped to a secret-free fingerprint of credential name plus endpoint, so one billed account cannot demote a still-free sibling that exposes the same provider/model pair. Requests with an `Idempotency-Key` skip cost-dependent evidence, while explicit quota/payment errors remain authoritative.
