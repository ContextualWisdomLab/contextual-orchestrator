Added a per-run spend guard, provider-limit drop, and tenant metering (ADR 0138). Every provider chat call — including `route_once`, streaming, and sampled baselines — is checked before send against an optional in-memory per-run USD cap (`--run-max-cost-usd`, default: no cap) plus optional LiteLLM-style virtual-key and tenant budgets (`max_budget`, `soft_budget`, `budget_duration`; the tightest limit wins). Paid admission uses a configured total-token ceiling priced at the costlier prompt/completion rate and reserves that upper bound before send. In-memory transactions cover concurrent run scopes; JSONL persists reservation/release events under a POSIX file lock so separate processes cannot spend the same headroom. Missing file-lock authority refuses shared hard budgets without disabling uncapped metering. Unknown outcomes, unknown historical costs, and crashes fail closed for the affected hard-budget scope while preserving unknown charged cost and inferring no expiry. Price/limit currency mismatch also fails closed without invented exchange rates. Ledger path I/O errors use the CLI argument-error surface, and recursive untrusted provider JSON cannot abort classification. The former `0.5` baseline threshold is removed; paid baselines under a hard cap require explicit allocation authority, while zero-cost or uncapped baselines can run. A provider spend-limit error (OpenRouter 402 `limit_source`, OpenAI 429 spend-limit codes, OpenCode Zen 401 `CreditsError`/`MonthlyLimitError`/`UserLimitError`, OpenCode Go 429 `GoUsageLimitError`, Bytez 402, Experiential 429 `insufficient_quota`, including mid-stream errors in an HTTP 200 stream) drops only that provider for the rest of the run; the run fails closed when none remain. Each provider call is metered as a tenant-attributed `UsageRecord` into an in-memory or append-only JSONL store (`--spend-ledger-path`), and the CLI can write a per-run usage summary artifact (`--run-usage-summary`).
