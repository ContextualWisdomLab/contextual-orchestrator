Fixed a ZDR-enforcement gap: a `zdr_only` request could still read a stale cached answer or write its own prompt/answer into the shared response cache (`ResponseCacheProvider`/Redis), since only an explicit caller `bypass_cache` skipped that path. `TaskOrchestrator.complete()` now always bypasses the response cache when the active request policy is `zdr_only`, regardless of caller-supplied cache flags.
